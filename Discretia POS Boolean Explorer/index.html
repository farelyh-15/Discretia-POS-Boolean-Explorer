Apa itu POS?

Product-of-Sum (Perkalian dari Penjumlahan)

Bentuk kanonik POS berfokus pada hasil fungsi yang bernilai 0 (salah) pada tabel kebenaran. Setiap baris yang menghasilkan 0 akan membentuk sebuah suku yang disebut Maxterm (M).

Aturan Maxterm:
Jika variabel bernilai 0 ➡️ Tulis literal asli (contoh: x)
Jika variabel bernilai 1 ➡️ Tulis literal komplemen (contoh: x')
Contoh: Jika baris x=0, y=1, z=0 menghasilkan f=0, maka Maxterm-nya adalah (x + y' + z).

Kalkulator Ajaib POS

Klik tombol nilai f(x,y,z) untuk mengubahnya menjadi 0, atau masukkan angka Maxterm Anda sendiri di bawah ini!

xyzMaxterm (M)f(x,y,z)

Pembuktian Manual

Misalkan kita memiliki fungsi: f(x,y,z) = x(y + z). Mari kita jadikan bentuk Kanonik POS secara manual langkah demi langkah. Gulir perlahan!

Langkah 1: Identifikasi kekurangan variabel di setiap suku.
Suku 1: x (kurang y dan z)
Suku 2: (y + z) (kurang x)
Langkah 2: Gunakan Hukum Identitas A + 0 = A dan Hukum Komplemen AA' = 0.
Suku 2 menjadi: (xx' + y + z)
Langkah 3: Gunakan Hukum Distributif pada suku 2.
(x + y + z)(x' + y + z)
Langkah 4 (Hasil Akhir): Jabarkan suku pertama dengan cara yang sama.
Maka didapat:
f(x,y,z) = (x+y+z)(x+y'+z)(x+y+z')(x+y'+z')(x'+y+z) 🌸
